## about me

I'm **Ali**, a Computer Science student at **VIT Vellore** who likes building AI systems that have to survive outside a notebook.

- 🧭 Currently building **[RoleAtlas](https://github.com/sting-raider/RoleAtlas)** — a qualification-first job discovery and application workspace.
- 🤖 Exploring **AI agents, reinforcement learning, robotics, and distributed systems**.
- 🧰 I care about measurable evaluation, honest AI outputs, privacy-friendly defaults, and software that is actually usable.
- 🌱 Open to internships and early-career **SWE / AI engineering** opportunities.

> I make cars and robot arms learn things the hard way, then build tools to make everyone else's life slightly easier.

## tiny engineering manifesto

- A working system beats a beautiful mock-up.
- An evaluation should tell me *how* something failed, not merely that it failed.
- AI recommendations should be traceable instead of pretending to be magic.
- If a boring process can be automated, I will probably over-automate it.
